IKEA RE:HOME｜競賽展示原型（可下載上線版）
==========================================

【先看網站】
直接用 Chrome 或 Edge 開啟 index.html。
本檔為獨立 HTML，無須安裝任何工具、無須 API 金鑰即可操作示範功能。

【GitHub Pages】
1. 確認 index.html 放在儲存庫 main 分支的根目錄，不要只上傳 ZIP。
2. GitHub 儲存庫 Settings → Pages → Deploy from a branch → main → /(root)。
3. 若已有舊版 RE:HOME 網站，應先以新版 index.html 覆蓋根目錄舊檔，並提交變更；Pages 才會更新。
4. 不必再次建立新儲存庫、也不必修改原本 GitHub Pages 的網址。

【可以點擊體驗】
• 首頁選買家或賣家（淡藍／淡黃背景），平台諮詢白底，明體字級小／中／大。
• 全台縣市與鄉鎮市區連動選擇、二手家具清單篩選、示意地圖、收藏。
• 新舊家具同系列比較、訂閱上架、在同一瀏覽器的示範上架通知。
• 賣家自評 A/B/C/D、原價／年數規則式參考估價、預設範例刊登。
• 商品詳情、站內示範對話、議價、預約實體驗貨與自取／物流選擇。
• 模擬案件進度、現金扣 5%／購物金加碼 10%（假設上限 NT$200）試算。
• C 級維修、D 級合作回收及 IKEA 官方選擇性回購的模擬申請。

【尚未真正連線的服務，請勿當作已上線】
• 沒有真實 AI 影像辨識、IKEA 正品驗證或照片 A/B/C/D 評級。上傳非家具照片不會獲得假的 AI 評分；可使用規則式自評示範估價。
• 沒有正式 IKEA 商品／成交價格資料庫、實際官方回購報價與實體驗收。
• 沒有真實跨裝置聊天室、金流代收代付、官方購物金／點數發放、GPS 或合作物流／回收 API。
• 模擬資料僅儲存於使用者當前瀏覽器，不會同步到其他裝置，請勿輸入敏感個資。
• 本網站是參賽團隊概念展示，非 IKEA 官方網站。若晉級決賽，團隊將依測試與評審回饋完善相關串接。

【展示建議】
A. 賣家 → 載入 B 級範例 → 自評折舊試算 → 示範刊登 → 切換買家 → 搜尋 → 聊天 → 議價 → 案件進度。
B. 賣家 → C 級範例 → 申請維修；D 級範例 → 合作回收；循環服務中心 → 官方回購。

注意：若網頁呈現舊版，先確認下載或上傳的是本套件根目錄的 index.html。
